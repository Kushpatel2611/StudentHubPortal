About CHARUSAT

Charotar University of Science and Technology (CHARUSAT) is located in Changa, Gujarat. It offers undergraduate, postgraduate and doctoral programmes in different fields.

About this StudentHub Portal

This portal is a full-stack academic web project engineered for the Web Development Framework curriculum (Practicals 7 through 14). It consolidates student identity management, event registration, directory lookups, and administrative control into a cohesive, secure platform.

The architecture features a robust PHP 8.2 backend, PDO prepared statements, session security with CSRF mitigation, MySQL relational database persistence, and asynchronous REST APIs for dynamic UI updates.

What you can find here

  • Dynamic student dashboard and database-backed profile management
  • Campus events with RSVP registration and poster management
  • Live student directory with real-time MySQL search and filtering
  • Role-based administration panel with audit logging and analytics

Architecture & Technologies

Built with PHP 8, MySQL/MariaDB (PDO), modern CSS3 with responsive dark/light themes, ES6 JavaScript modules, and automated MySQL integration testing.
